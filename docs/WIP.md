# Work in progress

This document lists planned work.

- **Linux packages:** packages that can be installed with apt on Debian and Ubuntu.
- **OpenWrt architectures:** packages are currently built only for `aarch64_cortex-a53`; packages for OpenWrt routers on other architectures will be added.
- **OpenWrt package feed:** submit the package to [openwrt/packages](https://github.com/openwrt/packages) so it can be installed directly with `opkg` or `apk` instead of downloading it from Releases!
